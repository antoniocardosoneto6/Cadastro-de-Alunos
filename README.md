## ✨ Sobre o projeto

O **Cadastro de Alunos** permite adicionar estudantes, validar as informações informadas, consultar médias e pesquisar registros pelo nome.

> Alunos com média maior ou igual a **6** são classificados como aprovados.

## 🚀 Funcionalidades

- ✅ Cadastro de alunos e notas
- ✅ Validação do nome e da nota
- ✅ Notas entre `0` e `10`
- ✅ Exibição da média com uma casa decimal
- ✅ Classificação como aprovado ou reprovado
- ✅ Busca de alunos em tempo real
- ✅ Destaque visual para as situações
- ✅ Mensagens de sucesso e erro
- ✅ Aviso quando nenhum aluno é encontrado

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/antoniocardosoneto6/Cadastro-de-Alunos.git
```

### 2. Acesse a pasta

```bash
cd Cadastro-de-Alunos
```

### 3. Execute o projeto

Abra o arquivo `index.html` em um navegador moderno.

Você também pode iniciar um servidor local:

```bash
npx serve .
```

Depois, acesse o endereço exibido no terminal.

---

## 📚 Como usar

1. Informe o nome do aluno.
2. Informe uma nota entre `0` e `10`.
3. Clique em **Cadastrar**.
4. Consulte o aluno na tabela.
5. Utilize o campo **Buscar aluno** para filtrar os resultados pelo nome.

### 🎯 Critério de aprovação

| Média | Situação |
| :---: | :---: |
| 6 a 10 | ✅ Aprovado |
| 0 a 5,9 | ❌ Reprovado |
